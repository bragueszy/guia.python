Booleanos — só há 2 valores

💡 Truque Python: Podes escrever 0 <= x < 10 em vez de x>=0 and x<10. Mais legível e cai bem no exame.

Ordem de avaliação — sem decorar, usa parênteses!

Aritméticos → Relacionais → not → and → or 
# Em caso de dúvida, mete parênteses:
x <= 1 + 2*y**3 or n != 0 and not 1/n <= y
# Melhor assim:
(x <= (1 + 2*(y**3))) or (n != 0 and not (1/n <= y))
⚠️ Short-circuit (avaliação preguiçosa): and e or só avaliam o 2º se precisarem. Usa a teu favor para evitar divisão por zero:
n != 0 and 1/n > 2 ✅ seguro   vs   1/n > 2 and n != 0 ❌ dá erro se n==0

As 3 formas de IF — receita visual

# 1) Só IF - faz ou não faz
if nota >= 10:
    print("Aprovado")

# 2) IF-ELSE - ou um ou outro (escolha binária)
if n % 2 == 0:
    print("par")
else:
    print("ímpar")

# 3) IF-ELIF-ELSE - várias faixas (notas, idades, preços)
if media < 10:
    m = "Insuficiente"
elif media < 14:
    m = "Suficiente"
elif media < 18:
    m = "Bom"
else:
    m = "Excelente"
🧩 Como resolver qualquer if: 1) Lista todos os casos possíveis → 2) Ordena do mais específico para o mais geral → 3) Usa elif para não repetir testes. Se usares só if soltos, podes executar 2 blocos ao mesmo tempo por engano.

Operador ternário — para poupar linhas

msg = "par" if n%2==0 else "ímpar"
# lê-se: "par se n for par, senão ímpar"
preco_final = preco * 0.9 if cliente_vip else preco

Simplificar IFs aninhados — truque de exame

Antes (confuso)Depois (limpo)
if a>=10: if b<3: R=2 else: R=3 else: R=1if a<10: R=1 elif b<3: R=2 else: R=3
✅ Leis para simplificar: not (A and B) = (not A) or (not B)   |   not (A or B) = (not A) and (not B)   |   x>y = not x<=y
❌ Erros mortais: 1) Usar = em vez de == → if x = 5: dá SyntaxError   2) Esquecer os : dois pontos   3) Indentação errada — tudo dentro do if tem de estar recuado 4 espaços.

Aula 3 — Funções Definir, chamar, parâmetros e return • O segredo para não repetir código

Definição vs Chamada — não confundas!

Definir = guardar receita

Não executa nada, só memoriza. Tem de vir antes da chamada.

Chamar = cozinhar

Aí sim o código corre. Podes chamar 100x.

def hms2sec(h, m, s):          # CABEÇALHO: def nome(parâmetros):
    sec = (h*60 + m)*60 + s    # CORPO indentado
    return sec                 # devolve resultado

# Chamadas (só depois da definição!)
print(hms2sec(1,30,0))     # 5400
total = hms2sec(0, 2, 15)

Return vs Print — a diferença que vale metade da nota

returnprint()
O que fazDevolve valor para usar no códigoMostra no ecrã (efeito)
Usa quandoQueres calcular algoQueres mostrar algo ao utilizador
Sem return?Devolve None
def quadrado(x):
    return x**2        # posso fazer quadrado(3)+1 = 10

def diz_ola():
    print("Olá!")     # void: não devolve nada útil
⚠️ Se a tua função calcula mas não consegues usar o resultado fora dela, falta-te o return. É o erro nº1 no exame.

Parâmetros e variáveis locais/globais

total = 0  # global

def soma(a, b):          # a,b são locais (só existem dentro)
    total = a + b      # este total é OUTRO, local
    return total

print(soma(10,20))   # 30
print(total)         # 0 - o global não mudou!
✅ Regra de escopo: Variável criada dentro da função é local (morre no fim). Parâmetros também são locais. Para alterar global precisas de global — mas no exame evita, faz antes return.

Argumentos por palavra-chave e defaults

def info(nome, idade=35):   # idade é opcional
    print(f"Nome: {nome}, Idade: {idade}")

info("Miki", 50)          # posicional
info("Miki")              # usa default 35
info(idade=50, nome="Miki") # por nome, ordem não importa

Lambda — função de uma linha

add = lambda a, b: a + b   # igual a def add(a,b): return a+b
dobro = lambda x: x*2

# Útil quando outra função pede uma função como argumento:
sorted(nomes, key=lambda s: len(s))  # ordena por tamanho
🧠 Receita para criar função no exame: 1) Nome verboso: calcula_media, eh_primo   2) Lista o que entra (parâmetros) e o que sai (return)   3) Escreve 2 testes à mão: assert calcula_media([10,20]) == 15   4) Escreve o corpo.

Aula 4 — Ciclos / Interação while e for • Como repetir sem copiar-colar

Quando usar cada um?

🔄 while — quando NÃO sabes quantas vezes

Ex: ler até o utilizador escrever "fim", validar input, jogo. Precisa de condição que eventualmente fique False, senão é infinito.

🔂 for — quando SABES onde iterar

Ex: percorrer lista, string, range(10). É o mais usado e seguro. Nunca é infinito.

# WHILE clássico
n = 3
while n > 0:
    print(n)
    n -= 1          # ATENÇÃO: sem isto, loop infinito!
print("Go!")

# FOR clássico
for n in [3,1,9]:
    print(n)

# FOR com range (o mais comum no exame)
for i in range(4):      # 0,1,2,3
    print(i)
for i in range(1,10,2): # 1,3,5,7,9 (ímpares)
    print(i)

range() — decora esta tabela

ChamadaGeraUso típico
range(4)0,1,2,3Percorrer 4 vezes
range(1,5)1,2,3,4De 1 a 4
range(5,0,-1)5,4,3,2,1Contagem decrescente
range(0,10,2)0,2,4,6,8Pares
⚠️ range para no stop-1: range(1,5) não inclui o 5. E só aceita inteiros.

break e continue — os comandos de fuga

# BREAK: sai imediatamente do ciclo (loop-e-meio)
while True:
    linha = input("Texto? (escreve 'fim') ")
    if linha == "fim":
        break        # salta para fora do while
    print(linha)

# CONTINUE: salta para a próxima iteração
for n in range(10):
    if n % 2 == 1:
        continue   # ignora ímpares
    print(n)       # só pares
✅ Padrões que caem sempre:
• Somar/acumular: soma=0; for x in lista: soma+=x
• Contar: cont=0; for x in lista: if cond: cont+=1
• Procurar: for x in lista: if x==alvo: print("achei"); break
• Validar input: while nota<0 or nota>20: nota=float(input("Nota?"))

Loop com else — evita!

⚠️ O else do for/while só corre se NÃO houver break. É confuso e raro no exame. Se vires, lê como: "se não interrompi, faz isto no fim". Na dúvida, não uses — faz um if depois do ciclo.
❌ Loop infinito: Esquecer de atualizar a variável do while. Sempre pergunta: "o que faz esta condição ficar False?" Se não houver resposta, falta o i+=1 ou break.

Indexação e Slicing — o coração

nums = [10, 20, 30, 40]
# índices:   0    1    2    3     ou   -4  -3  -2  -1
nums[0]     # 10 (primeiro)
nums[-1]    # 40 (último - truque de ouro!)
nums[1:3]   # [20,30]  (do 1 até antes do 3)
nums[:2]    # [10,20]  (do início)
nums[3:]    # [40]     (até ao fim)
nums[:]     # cópia completa!
nums[::-1]  # [40,30,20,10] invertida
nums[::2]   # [10,30] de 2 em 2
✅ Regra slicing: lista[inicio:fim:passo] — fim nunca entra. Se omitires, vai até ao limite. Negativo conta do fim.
# Strings igual às listas
fruta = "banana"
fruta[0]      # "b"
fruta[1:4]    # "ana"
fruta[::-1]   # "ananab" (inverter - cai no exame!)
len(fruta)   # 6
"ana" in fruta # True - substring?

Percorrer — 4 formas (sabe as 2 primeiras)

frutas = ['banana','pera','laranja']

# 1) Direto (preferida)
for f in frutas:
    print(f)

# 2) Com índice (quando precisas da posição)
for i in range(len(frutas)):
    print(i, frutas[i])

# 3) Com enumerate (elegante)
for i, f in enumerate(frutas):
    print(i, f)

# 4) While (evita, mas pode cair)
i=0
while i < len(frutas):
    print(frutas[i]); i+=1

Aliasing — a armadilha mortal do exame

❌ ATENÇÃO: variáveis guardam REFERÊNCIAS, não cópias!
a = [1,2,3]
b = a           # b NÃO é cópia, é ALIAS (mesmo objeto!)
b[0] = 9
print(a)      # [9,2,3] - a também mudou! 😱
a is b        # True - são o mesmo objeto
a == b        # True - valores iguais (mas is é mais forte)

# Como fazer cópia de verdade:
c = a[:]        # fatiamento
c = a.copy()    # método copy
c is a        # False - agora são diferentes
✅ No exame: Se passas lista para função e ela faz lst.append(), a lista original muda! Se não queres isso, copia dentro da função: r = lst[:]
def cresce(lst):
    r = lst[:]      # cópia
    r.append(3)
    return r        # original intacta

== vs is — não confundas

TestePerguntaExemplo
==Valores iguais?[1,2]==[1,2] → True
isMesmo objeto?[1,2] is [1,2] → False (2 objetos diferentes)
⚠️ Nunca uses is para comparar valores, só para None ou identidade. No exame, == é quase sempre o certo.

Strings — imutáveis mas poderosas

# NÃO podes fazer: fruta[0] = "A" → TypeError
# Tens de criar nova:
fruta = "banana"
nova = fruta[:-1] + "utan"  # "orangutan"

# Métodos que criam nova string (original não muda):
"ola".upper()          # "OLA"
"  ola  ".strip()      # "ola" (tira espaços)
"a,b,c".split(",")    # ["a","b","c"]
",".join(["a","b"])   # "a,b"
"ola".replace("a","A") # "olA"
"banana".count("a") # 3

Tuplos — e zip/enumerate

t = ("a", "b", "c")   # ou "a","b","c"
t1 = ("a",)                  # 1 elemento precisa da vírgula!
tuple("ape")              # ("a","p","e")

# zip junta 2 listas
list(zip("abc", [1,2,3]))  # [("a",1),("b",2),("c",3)]

# enumerate dá índice + valor
for i, c in enumerate("abc"):
    print(i, c)  # 0 a, 1 b, 2 c

Aula 6 — Ficheiros Ler/escrever ficheiros, argumentos e exceções • Para o programa não morrer

Abrir e fechar — o padrão que tens de saber

# FORMA MODERNA (usa sempre esta - fecha sozinho):
with open("dados.txt", "r", encoding="utf-8") as f:
    for linha in f:

# Modos: "r"=ler, "w"=escrever (apaga!), "a"=adicionar ao fim

Assert — para testar

def kelvin_para_f(t):
    assert t >= 0, "abaixo do zero absoluto!"
    return ((t-273)*1.8)+32

💡 Quando usar: assert para verificar que a tua função está correta durante o desenvolvimento. try/except para erros que o utilizador pode provocar (ficheiro não existe, input errado). No exame, se pedirem "valide", usa assert ou if + raise.
